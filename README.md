# Primate LED — sitio institucional

Sitio estático listo para GitHub y Cloudflare Pages.

## Estructura

- `index.html`: contenido y estructura semántica.
- `assets/css/styles.css`: diseño completo y responsive.
- `assets/js/main.js`: navegación móvil, animaciones y año automático.
- `assets/images/`: imágenes optimizadas en WebP y recursos de marca.

## Publicación en Cloudflare Pages

1. Crear un repositorio en GitHub y subir esta carpeta.
2. En Cloudflare Pages, elegir **Connect to Git**.
3. Framework preset: **None**.
4. Build command: dejar vacío.
5. Build output directory: `/`.
6. Después del despliegue, agregar `primate.ar` en **Custom domains**.

## Datos fáciles de editar

- WhatsApp: buscar `5492914420835` en `index.html`.
- Email: buscar `contacto@primate.com.ar`.
- Redes: están en el footer de `index.html`.
- Colores principales: están al inicio de `assets/css/styles.css`.

## Observación

El sitio usa Google Fonts. Si se desea operar sin recursos externos, se pueden reemplazar por tipografías del sistema o alojar fuentes web propias con sus licencias correspondientes.
